Instagram engagement rate calculator

Estimate follower-based engagement using average likes and comments per post. This is a simple comparison metric, not an official Instagram score or a complete measure of audience quality.

Calculate engagement rate

Enter your figures to calculate an estimate. Values are processed in this browser.

Formula: (average likes + average comments) ÷ followers × 100.

Formula and worked example

Follower-based engagement rate (%) = (average likes + average comments) ÷ follower count × 100.

For example, if an account has 5,000 followers and its recent posts average 250 likes and 20 comments: (250 + 20) ÷ 5,000 × 100 = 5.4%.

How to make comparisons more useful

  • Use the same number of recent posts for each account.
  • Compare similar content types and audience sizes.
  • Separate Reels, photos and other formats when their interaction patterns differ.
  • Use averages rather than selecting only the best-performing post.
  • Note the date range, since audience size and interactions change over time.

Follower-based vs reach-based engagement

This calculator uses followers as the denominator. A reach-based rate uses accounts reached instead. These metrics answer different questions and should not be compared as if they were identical. Reach-based calculation also requires reliable reach data that may be available only to the account owner.

What this number does not tell you

A higher rate does not automatically mean more sales, stronger brand fit, genuine followers or better content. Audience size, content format, paid distribution, posting frequency and audience interests all affect the result. Avoid universal “good engagement rate” thresholds without context.

Frequently asked questions

Is this Instagram's official engagement score?

No. It is a simple estimate using the inputs you provide, not an official Instagram metric.

How many posts should I average?

Use a consistent, recent sample large enough to avoid relying on one unusually strong or weak post. Keep the sample size consistent when comparing accounts.

Can I use views instead of likes?

You can define other metrics, but that changes the formula. This calculator specifically uses likes plus comments divided by followers.
