# FollowLens: Instagram Non-Followers Checker

Free-to-start Instagram non-followers checker, unfollow tracker, fake follower signals and post engagement analyzer. Public data only. No Instagram password needed.

**App:** https://followlensig.onrender.com/
**Website and guides:** https://im-mohid.github.io/Followlens/

## Features
- See who doesn't follow you back (fans, mutuals, confirmed non-followers)
- Unfollow tracker: new and lost followers between two scans
- Engagement rate: average likes, comments, best day and hour, top hashtags
- Fake follower and fake engagement signals (an estimate, not proof)
- Post and reel analysis from a public link
- Export lists as CSV

## Pricing
First 200 followers + 200 following free, 2 post analyses per day. Larger accounts use credits (about $1 per 1,500 accounts, minimum 3). Pay once, no subscription. bKash, Nagad, Rocket, PayPal, USDT.
