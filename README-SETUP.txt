FOLLOWLENS SEO WEBSITE PACKAGE
================================

All files are in this single root directory. No nested folders are required.

PUBLISHING
1. Download and extract the ZIP.
2. Open your GitHub repository: im-mohid/Followlens.
3. Replace the repository's root files with the files from this package.
4. Keep every file at repository root (same level as index.html).
5. Commit and push to the branch configured for GitHub Pages.
6. Wait for GitHub Pages deployment, then open https://im-mohid.github.io/Followlens/.

IMPORTANT: This package assumes the public website remains at:
https://im-mohid.github.io/Followlens/
If you change the domain or repository path, update BASE URLs in every HTML file,
sitemap.xml, robots.txt, feed.xml, manifest.webmanifest and sw.js.

BEFORE PUBLICATION — REQUIRED FACT CHECKS
1. Privacy policy and terms are templates. Confirm actual server logging, data retention,
   payment processing, deletion process and support contact details.
2. Confirm the free limits, paid prices, payment methods and credit rules in the live app.
3. Ensure every feature described is actually available and works on production.
4. The package deliberately avoids guaranteeing 100% accuracy or Google ranking.
5. Google does not use the meta keywords tag for ranking. This package omits keyword stuffing.
6. Do not create fake reviews, fake ratings, fake author credentials or fake backlinks.
7. Add original screenshots, demonstrations, transparent methodology and genuine author
   information when available. Those improve usefulness more than repeating keywords.

SEO NOTES
- Each page has a unique title, description and canonical URL.
- The sitemap lists the published pages.
- Internal links connect related guides.
- Structured data is limited to factual website/software information; do not add fake review
  or rating markup.
- Keep pages useful, distinct and updated. Avoid publishing thin near-duplicate pages.
- Check Core Web Vitals and indexing in Google Search Console after deployment.
